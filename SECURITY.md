# Security

Duplicity runs entirely in the browser and never uploads saves, but a malicious save file could still target the parser or the page.

Report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/nomansheikh/oni-duplicity/security/advisories/new), not in a public issue. Include a sample file if one triggers the problem.

Only the latest release is supported. You'll get a reply within a week.
